## Memory Architecture Overview

### Allocation Strategy

**Single-Pass Allocation:**
```cpp
// SDStyleFactory::make() - called at preset activation
1. Allocate file buffer (16KB, freed after parsing)
2. Parse into RtColorNode tree (recursive allocations)
3. Return new RuntimeBladeStyle(root)
```

**Memory Ownership:**
- **Allocation owner:** SDStyleFactory::make() (via new)
- **Lifecycle owner:** Preset system (via preset_allocator)
- **Deallocation owner:** Preset system (via delete on BladeStyle)

### Memory Hierarchy

```
RuntimeBladeStyle (new)
└── RtColorNode* root_
    ├── RtCompose (new)
    │   ├── RtColorNode* base_
    │   └── RtColorNode* layer_
    ├── RtAlphaL (new)
    │   ├── RtColorNode* color_
    │   └── RtFuncNode* alpha_
    ├── RtRgb (new)
    ├── RtColorCycle (new)
    │   └── RtColorNode* base_
    └── ... (other effect nodes)
```

**Key Property:** Each parent owns its children. Destructor calls delete on all children.

## Code Inspection: Memory Safety

### 1. RtVec Template - Vector Replacement

**File:** styles/sd_style.h, lines 86-126

**Code:**
```cpp
template<typename T>
class RtVec {
public:
  RtVec() : data_(nullptr), size_(0), cap_(0) {}
  ~RtVec() { if (data_) free(data_); }  // ✅ Proper cleanup
  void push_back(const T& v) { grow_if_needed(); data_[size_++] = v; }
  void resize(int n, T val = T()) {
    if (n > cap_) { data_ = (T*)realloc(data_, n * sizeof(T)); cap_ = n; }
    for (int i = size_; i < n; i++) data_[i] = val;
    size_ = n;
  }
private:
  void grow_if_needed() {
    if (size_ < cap_) return;
    int new_cap = cap_ ? cap_ * 2 : 4;
    data_ = (T*)realloc(data_, new_cap * sizeof(T));  // ✅ Safe realloc
    cap_ = new_cap;
  }
  T* data_; int size_, cap_;
};
```

**Assessment: ✅ SAFE**
- Destructor calls `free(data_)` if allocated
- RAII pattern (Resource Acquisition Is Initialization)
- `realloc()` used correctly for resizing
- No double-free or use-after-free risks

### 6. RuntimeBladeStyle - Final Container

**File:** styles/sd_style.h, lines 1465-1495

**Code:**
```cpp
class RuntimeBladeStyle : public BladeStyle {
public:
  explicit RuntimeBladeStyle(RtColorNode* root) : root_(root) {}
  ~RuntimeBladeStyle() override {
    delete root_;  // ✅ Delete entire tree recursively
  }

  void run(BladeBase* blade) override {
    root_->run(blade);
    int n = blade->num_leds();
    bool blade_off = !blade->is_on();
    bool all_zero = blade_off;
    for (int i = 0; i < n; i++) {
      RGBA_um c = root_->getColor(i);
      Color16 out = (c.alpha >= 32768) ? c.c : (c.c * c.alpha) >> 15;
      if (all_zero && (out.r || out.g || out.b)) all_zero = false;
      if (c.overdrive)
        blade->set_overdrive(i, out);
      else
        blade->set(i, out);
    }
    // Power control check
    if (all_zero && root_->canPowerOff()) {
      blade->allow_disable();
    }
  }

  bool IsHandled(HandledFeature) override { return false; }

private:
  RtColorNode* root_;  // ✅ Owns the entire tree
};
```

**Assessment: ✅ SAFE**
- Destructor deletes root_, which triggers recursive cleanup
- Virtual destructor ensures correct derived class cleanup
- run() method safely accesses tree without modification
- No reference issues or use-after-free risks

## Memory Lifecycle: Activation → Deactivation

### Scenario 1: Single Preset Activation

```
PresetSystem:
1. Load preset #1
2. Create preset_allocator = StyleFromSD("style1.style")
3. Call preset_allocator->make()
   │
   └─→ SDStyleFactory::make()
       1. Open file
       2. Allocate 16KB buffer
       3. Parse into RtColorNode tree
       4. Free 16KB buffer
       5. Return new RuntimeBladeStyle(root)
       └─ Returns BladeStyle* instance
4. Store BladeStyle* in blade_style[0]
5. Per-frame: blade_style[0]->run(blade)
```

**Memory State:**
- RtColorNode tree: ALLOCATED (root_ points to it)
- File buffer: FREED (after parsing)
- Total RAM: ~2-20 KB depending on style complexity

---

### Scenario 2: Preset Switch

```
PresetSystem:
1. Currently running preset #1 (blade_style[0] allocated)
2. User selects preset #2
3. System calls delete blade_style[0]
   │
   └─→ RuntimeBladeStyle::~RuntimeBladeStyle()
       └─→ delete root_
           └─→ RtCompose::~RtCompose()
               ├─→ delete base_  (recursively)
               └─→ delete layer_  (recursively)
4. Create new preset_allocator = StyleFromSD("style2.style")
5. Call make() → returns new RuntimeBladeStyle(new_root)
6. Store in blade_style[0]
7. Per-frame: blade_style[0]->run(blade)
```

**Memory State Before Switch:**
- Preset #1 RtColorNode tree: ALLOCATED
- RAM: ~2-20 KB

**Memory State After Switch:**
- Preset #1 tree: FREED (via recursive delete)
- Preset #2 tree: ALLOCATED
- RAM: ~2-20 KB (similar size, no accumulation)

**Key Property:** ✅ No memory accumulation. Old preset fully freed before new preset allocated.

---

### Scenario 3: Repeated Activation/Deactivation

```
Repeated 10 times:
1. Load preset #1 → allocate → run 100 frames → delete
2. Load preset #2 → allocate → run 100 frames → delete
3. Load preset #1 again → allocate → run 100 frames → delete
... etc
```

**Memory Behavior:**
- Each delete fully frees previous preset tree
- New allocation reuses freed memory (OS memory manager)
- No memory growth or fragmentation
- ✅ Safe for indefinite switching
