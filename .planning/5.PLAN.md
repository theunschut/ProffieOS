  5. **REQUIREMENT:** variance <= 5%

  - If FPS counter available in config: read from serial output
  - If frame counter available: calculate fps = frame_count / elapsed_seconds
  - If only visual observation: estimate (60fps smooth, <50fps noticeable slowdown)

  - [ ] Is the variance consistent or inconsistent?
