- RtColorAdapter and RtFuncAdapter use inheritance to wrap ProoffieOS base classes
- Template specialization requires access to protected members
- This is a standard C++ pattern and doesn't break encapsulation (derived classes are in sd_style.h)

**Risk assessment:** 🟢 **ZERO RISK**
- No logic changes, only visibility changes
- All changes are in the same file (sd_style.h is the only consumer)
- No behavioral impact on compiled styles
- Backward compatible (protected ≥ private visibility-wise for this use case)
