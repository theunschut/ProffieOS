## The Four Known Issues

### Issue 1: Fast Ignition Regression
**Problem:** Ignition animation appears slow or stuttering vs compiled equivalent
**Priority:** HIGH (user-facing performance)
**Estimated Fix Time:** 2 hours
**Key Classes:** RtIgnitionDelay, IgnitionDelayBase
**Success Metric:** Timing within 10% of compiled

### Issue 2: Pre-Ignited Color
**Problem:** Blade shows color before ignition event
**Priority:** HIGH (user-visible bug)
**Estimated Fix Time:** 1.5 hours
**Key Classes:** RtAlphaL, RtColorNode, blade state checking
**Success Metric:** Blade dark until ignition

### Issue 3: Missing Effects Parsing
**Problem:** Some effect tokens don't parse or parse incorrectly
**Priority:** MEDIUM (functional coverage)
**Estimated Fix Time:** 2 hours
**Key Classes:** Parser (all effect sections), Rt* effect wrappers
**Success Metric:** All expected effects parse successfully

### Issue 4: Return Value Semantics
**Problem:** Blade can't power down because run() doesn't signal power-off
**Priority:** HIGH (battery drain / functionality)
**Estimated Fix Time:** 1.5 hours
**Key Classes:** RtColorNode, RtFuncNode (base), all effect classes
**Success Metric:** Blade powers off when effects complete
