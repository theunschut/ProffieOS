## Technical Details

### Parser Enhancement
```cpp
// New: Parse preset.style = StyleFromSD("path") entries
if (!strncmp(variable, "preset.style", 12)) {
  const char* sd_path = parseStyleFromSD(style_str);
  if (sd_path) {
    const char* resolved = resolveStylePath(sd_path);
    current_style_[blade_num] = ValidateStyleString(resolved);
  }
}
```

### Path Resolution Strategy
```cpp
// Try paths in order:
1. /config/styles/{filename}  ← Primary (ProffieOS standard)
2. /styles/{filename}         ← Secondary
3. {filename}                 ← Tertiary (user provided)
4. Return Black if not found  ← Safe fallback
```

### Memory Lifecycle
```
SDStyleFactory::make()
├─ Allocate 16KB file buffer
├─ Parse style into RtColorNode tree
├─ Free file buffer
└─ Return new RuntimeBladeStyle(root)
    └─ Destructor: delete root_ (recursive cleanup)
```

## Technical Decisions Made

### Decision #1: Path Resolution Order
**Chosen:** Try /config/styles/ first, then /styles/, then raw path
**Rationale:** Follows ProffieOS conventions, user-friendly
**Alternative:** Only try one path (less flexible)
**Impact:** Better UX without performance cost

### Decision #2: Graceful Degradation
**Chosen:** Missing files return safe Black style, log warning
**Rationale:** Better than crash or hang
**Alternative:** Strict failure (user must fix paths)
**Impact:** Saber remains responsive even with config errors

### Decision #3: No ROM Preset Support (Phase 4)
**Chosen:** StyleFromSD() only in presets.ini (disk presets)
**Rationale:** Simpler implementation, sufficient for Phase 4 goals
**Alternative:** Support ROM presets too (more complex)
**Impact:** Acceptable limitation, documented for future
