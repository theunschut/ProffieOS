## Implementation Pattern

Reuse existing ProffieOS templates via adapter pattern (proven in Phase 4):

```cpp
// Template base class in ProffieOS
template<typename BASE_COLOR, typename MIX_FUNC>
class HumpFlickerL { ... };

// Runtime adapter wraps it
class RtHumpFlickerL : public RtColorNode, public HumpFlickerL<RtColorAdapter, RtFuncAdapter> {
  using Base = HumpFlickerL<RtColorAdapter, RtFuncAdapter>;
public:
  RtHumpFlickerL(RtColorNode* c1, RtColorNode* c2, RtFuncNode* width) {
    color1_.node_ = c1; color2_.node_ = c2; width_.node_ = width;
  }
  void run(BladeBase* blade) override { Base::run(blade); }
  RGBA_um getColor(int led) override { return Base::getColor(led); }
};
```

**Key Benefit:** No reimplementation. Correctness + performance inherited.
